Why declarative, drawn

What a hand-edited data.json renders as

data.json is a file the user can edit, so it is a trust boundary rather than a formality. Every value passes settingsFrom on the way in and on the way out. This is that gate with a face on it.

The middle row is the one worth arguing about: a bad value produces no message. That is deliberate — the file is not a form and the user may never open the pane — but it means a typo is undiagnosable from the UI. Whether an unrecognised value deserves a notice is open, and it is a Toast-versus-silence question rather than a settings one.
