# Accessibility

§44's list, which no product epic can own because it appears in all of them: keyboard support, visible
focus, sufficient contrast, no colour-only status encoding, and an alternative list or table route to
anything spatial.

It sits at MVP horizon rather than later on purpose. Every one of these is cheap while there is one view
and expensive once there are twenty, and the alternative-list requirement in particular is a design
constraint on each screen rather than something that can be added to a finished one.

## Outcome

Everything the plugin can do is reachable without a pointer and without distinguishing colours.
