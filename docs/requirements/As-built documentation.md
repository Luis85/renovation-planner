# As-built documentation

§30's last step and §35's terminal state: what was actually built, as opposed to what was planned. For a
private renovator this is the artefact with the longest life — it outlives the project by decades and is
what the next owner, the next trade or the insurer reads.

It needs the removed objects as much as the installed ones, which is why §30 keeps a `to-remove` object
in the model after it is gone.

## Outcome

When the work is finished the renovator has an accurate record of what is actually in the house.
