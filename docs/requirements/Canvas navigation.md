# Canvas navigation

Pan and zoom (§13), against §44's requirement that it stay smooth with several hundred spatial
objects on the plan. It is listed as a feature because it is the interaction a user performs more
than any other, and because §66's rule lives here: pointer movement is transient and must not
reach the vault.

Keyboard navigation is part of this feature and not a later polish item — §44 requires it, and a
canvas is where a pointer-only design excludes somebody completely.

## Outcome

Moving around a large plan stays smooth, works from the keyboard, and writes nothing to the vault
while it happens.
