# Change history

§25's change history, append-only. A superseded decision is kept rather than edited, because the value
of the history is precisely the choices that were later reversed — those are the ones somebody will
want to understand, and the ones an edit-in-place model destroys first.

Git already versions the files; what this adds is the *domain* history, legible to somebody reading the
vault rather than the repository.

## Outcome

A renovator can read back the order in which the plan changed and what each change was for.
