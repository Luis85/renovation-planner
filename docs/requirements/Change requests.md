# Change requests

§25's change requests: a proposed change to a plan that has already been committed to, kept as its own
object so it can be costed and argued about before it is accepted. On a private renovation the
requests usually come from reality rather than from a client — the tiles are discontinued, the joists
are shallower than assumed — and they are exactly the changes that get made without being recorded.

## Outcome

A renovator can propose a change, see what it would cost and delay, and decide before committing to it.
