# Completion evidence

§27's completion evidence: what closes a piece of work. Photos, a signed sheet, a test certificate, a
delivery note. The requirement worth stating is the negative one — a work package closed with no
evidence is visibly closed with no evidence, rather than looking identical to one that was properly
signed off.

It matters most for work that gets covered up, which on a renovation is most of the expensive work.

## Outcome

A renovator can tell which finished work is actually evidenced and which is only marked done.
