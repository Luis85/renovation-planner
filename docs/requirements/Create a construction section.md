# Create a construction section

§16's create step: naming a measure — *replace the bathroom*, *rewire the ground floor*, *insulate
the roof* — as a thing with its own note, ID and lifecycle. It is the object a renovator thinks in
and the one they will later award, budget and schedule, so it exists before any of those epics do.

## Outcome

A renovator can name the actual jobs their renovation consists of, separately from the rooms they
happen in.
