# Create a project

The first act in the product, and the one that decides whether the vault gets a tidy home or a
scattering of notes. PRD §12 asks for project creation; PRD §36 says the folder layout must be
configurable, so creation has to offer a default that is good enough to accept without thought
and a path that a user who already organises their vault can override.

## Outcome

A renovator can start a project in a few seconds and find its notes exactly where they expected
them to be.
