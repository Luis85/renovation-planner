# Create a task from context

§20's first feature, and the one that carries the epic: a task created from a zone, an asset, a work
package or a construction section keeps the link back to where it came from. That link is what
later lets a photo, a cost or a delay attach to the right thing, and it is unrecoverable if the task
was typed into a list instead.

## Outcome

A renovator can turn anything they are looking at into a task, and the task remembers what it came
from.
