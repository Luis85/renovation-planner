# Dependencies

§77's permitted pairs and §78's three types — finish-to-start, blocking, informational — kept in one
place so that [[Timeline]], [[Procurement requirements and lifecycle]] and
[[Decisions, scenarios and change management]] all read one model. This is the feature most likely
to be reinvented three times if it is not owned somewhere explicit, and three dependency models that
disagree is worse than none.

Three types rather than the full vocabulary of project management is deliberate: §78 calls it
initial, and a renovator does not need start-to-finish.

## Outcome

A renovator can say what has to happen before what, once, and every view that cares reads the same
answer.
