# Document linking and types

§23's document linking and document types. The link is the feature — Obsidian already stores the
file — and the type list (quote, invoice, delivery note, data sheet, installation manual, permit,
warranty, contract, photo, sketch, other) is a starting vocabulary that §84 makes extensible.

The question this exists to answer is never chronological. It is "what is the warranty on the thing
in that room", which only a link can answer.

## Outcome

Every document a renovation produces is attached to the thing it is about, and findable from it.
