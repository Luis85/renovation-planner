# Existing versus target view

§30's existing versus target view: the same plan shown as it is now and as it is meant to end up. Two
views of one model, never two stored copies — copies are how the before and the after come to disagree
about a wall that neither of them was supposed to move.

It is also the view a renovator shows other people, because the difference between the two pictures is
the entire project in one glance.

## Outcome

A renovator can flip between how the house is now and how it will be, from a single plan.
