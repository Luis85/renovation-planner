# Object states

§30's six states — existing, to-remove, to-retain, planned, in-progress, installed — as a property of
any spatial object. This one feature carries the epic: with it, a wall that is coming down and a wall
that is going up are distinguishable, and every quantity downstream can ask which it is dealing with.

The states cover §30's verbs: retain, remove, modify and new are all expressible as an existing object
in a state, which is why they are not four separate features.

## Outcome

Every object on a plan says whether it is already there, going, staying, planned or built.
