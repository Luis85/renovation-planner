# Obsidian task integration

§20 asks for this explicitly, and it is a statement about what the plugin refuses to be. An Obsidian
user already has checkboxes, queries and whichever task plugin they chose; a private task format
would make the renovation the one part of their vault their own tooling cannot see, and §3.6 calls
being Obsidian-native a principle rather than a nicety.

§65 is the consequence: a task ticked by hand in the note is the normal case, not an edge case, and
must never be overwritten.

## Outcome

Renovation tasks appear in whatever the renovator already uses to see their tasks, and ticking one
there counts.
