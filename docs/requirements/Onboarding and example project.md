# Onboarding and example project

§93, §94 and §95 together: what the plugin says on first run, what every empty view says instead
of showing nothing, and an example project that demonstrates the spatial premise rather than
describing it. This is a first-run concern and not documentation — a renovator decides in about
two minutes whether a plugin is worth learning, and the calibration step is the one that has to
be understood in that window or the product looks like a drawing toy.

## Outcome

Somebody who has just installed the plugin gets to a measured plan with a cost on it without
reading anything.
