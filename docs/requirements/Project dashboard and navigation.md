# Project dashboard and navigation

§12's dashboard and navigation, plus the status, budget and date range it puts on the project
itself. This is one project's own front page — where its plans, zones and sections are, and how
far along it is. The aggregate view, the forecast and project health are
[[Reporting and project cockpit]]; the two are separated so this one can exist in V1 without
waiting for that epic.

## Outcome

Opening a project shows what state it is in and gets a renovator to any part of it without
hunting through folders.
