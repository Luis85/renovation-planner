# Project health

§28's project health: one summary of whether the renovation is in trouble. A single indicator is only
worth having if it can be taken apart, so the requirement that matters is that it always says what
made it what it is — and, per §44, that it never says it with colour alone.

## Outcome

A renovator gets one honest answer about whether the project is in trouble, and can see exactly why.
