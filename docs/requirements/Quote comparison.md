# Quote comparison

§22's compare quotes. The comparison a renovator actually needs is not quote against quote — those
never cover the same scope — but each quote against *the plan*, which is the only fixed reference
available. That is what turns "three prices for the bathroom" into a statement about what is missing
from the cheapest one.

It is a derived view (§88) and writes nothing back; choosing a quote is a decision, and belongs to
[[Decisions and alternatives]].

## Outcome

A renovator can see how each offer covers the plan, including the parts it quietly leaves out.
