# Renovation semantics

The plan editor becomes a renovation surface when a selected room can answer four connected
questions: what exists now, what should exist afterwards, what work produces that outcome, and
whether the spatial scope is ready to act on. This feature owns those workflows and their
canvas/Inspector projections. It does not own the domain meaning of object states, work,
dependencies, project health, evidence or issues; it consumes those authorities.

One spatial identity connects every projection. Existing details, planned outcomes and canonical
work refer to the selected room or object by stable identity and never copy its geometry. A
capability that has not landed is unavailable, not a failed or empty result.

## Outcome

A renovator can move from a room's present state through its intended outcome to canonical work
and an explainable readiness review without the plan editor becoming a second project-data system.
