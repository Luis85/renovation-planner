# Revision lifecycle

§31's five states: draft, proposed, approved, superseded, as-built. `superseded` is what makes
immutability survivable — a plan does keep changing, and the answer is a new revision rather than an
edit — and `as-built` is the joint where this epic meets
[[Existing state, planned change and as-built]].

## Outcome

A renovator can tell which version of a plan is the one being worked to, and which are history.
