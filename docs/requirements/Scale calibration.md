# Scale calibration

§82's minimum: two points and one known distance, which is a measurement a renovator can actually
take with a tape measure against a wall they can reach. §81 keeps the background image and the
world coordinate system separate, so calibrating is establishing the transform between them rather
than editing the image.

The value is that this is the single step that converts the product from a drawing tool into a
planning tool, and it takes about fifteen seconds. Multiple control points are named as future
work in §82 and are not this feature.

## Outcome

After typing one real-world distance, everything a renovator draws on that plan has true
dimensions.
