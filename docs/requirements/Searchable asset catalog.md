# Searchable asset catalog

§17's searchable catalog. A library only saves work if the thing already in it can be found in less
time than defining it again — otherwise a renovator defines *white wall paint* four times and the
library becomes the problem it was meant to solve.

§40's search requirements and §41's Bases integration are the route: the catalog should be
searchable through Obsidian's own machinery rather than only through a picker this plugin draws.

## Outcome

A renovator finds the asset they already defined before they get round to defining it twice.
