# Task lifecycle and dates

§20's task status, due date and dependencies. Five states — todo, in-progress, blocked, done,
cancelled — and `blocked` is again the one that matters: on a renovation the blocked tasks are the
project, and a system that can only say *not done* cannot tell a renovator what to chase.

Dependencies reuse [[Dependencies]] rather than a task-local mechanism.

## Outcome

A renovator can see what is due, what is running and what is stuck, per task.
