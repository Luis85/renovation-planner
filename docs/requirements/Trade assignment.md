# Trade assignment

§16 lists trade assignment among a section's features, and §48 leaves trades out of the MVP, so
this is the V1 feature that joins the two epics. Assigning is a link into the catalog owned by
[[Trade catalog]] rather than a typed name — two spellings of *Elektriker* is a silent split of one
trade's work, budget and schedule into two.

## Outcome

Each job says which trade does it, drawn from one list rather than typed each time.
