# Work package creation and scope

§19's work package creation and spatial scope. A work package is the unit a trade is awarded and
paid for, and its scope is a reference to zones and construction sections rather than geometry of
its own — the moment it holds a copy, a plan change stops reaching the work that was priced from it.

It is where a renovation stops being a description and becomes a set of things somebody can be
asked to do.

## Outcome

A renovator can define a piece of work with a clear boundary, and that boundary follows the plan
when the plan changes.
