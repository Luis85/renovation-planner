# Work package progress

§19's progress: how far along a package is, derived from the tasks it contains (§88) rather than
typed over the top. A percentage somebody typed is the number that stays at ninety for three weeks,
and it is the reason progress reporting gets distrusted.

The execution-side counterpart is [[Planned versus actual progress]]; this feature is the roll-up,
that one is the comparison.

## Outcome

A piece of work reports how far along it is from what has actually been finished inside it.
