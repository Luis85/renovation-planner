That skill's rule is that a running plan does not wait on a human: conflicts, ambiguities,
plan defects and caps are DECIDED, each decision written down as *what was decided, why, and
what it costs if wrong*, and the run continues. A wrong ruling costs rework a reader can see
and undo; a session parked on a question costs a day and buys nothing.

**This file exists because the ledger those rulings were written in is git-ignored scratch
that the skill deletes when the branch finishes.** A record of seventy-five decisions kept
only in a directory something is about to remove is a record nobody inherits — which is this
repository's own recurring lesson about a limitation written in prose that nothing schedules,
applied to the decisions rather than to the limitations.

Read it as an audit trail, not as documentation of the code: each entry names the moment it
was taken, so a decision you disagree with can be found, and the thing it decided can be
undone.
