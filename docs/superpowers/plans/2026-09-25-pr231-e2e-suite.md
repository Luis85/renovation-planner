# PR 231 native e2e suite — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer PR 231's vault-run questions (Q2, Q3, the leaf-owned incident, BP-04, A01, the
mobile guards, contrast on the new surfaces) with cases that drive a real Obsidian.

**Architecture:** One `.e2e.ts` file per question area under `tests/e2e/`. Every file runs through
the existing harness (`fixture.ts`'s `test`, which gives each case a fresh Obsidian, profile and
copied vault). Helpers used by two or more files live in `tests/e2e/planner.ts`. Measurements the
owner needs are written as evidence under `e2e-results/`.

**Tech Stack:** Vitest 5 in node mode, standalone WebdriverIO, `wdio-obsidian-service` 3.x,
Obsidian 1.13.7, and `@axe-core/webdriverio`.

**Spec:** `docs/superpowers/specs/2026-09-25-pr231-e2e-suite-design.md`. Read it first: it says
which manual-case row and which tracker row each case answers.

## Global Constraints

- Work in `C:\Projects\renovation-planner\.worktrees\pr231`, on branch `pr231-e2e`. Never push; the
  controller pushes.
- **Nothing in `src/` changes.** A mutation is temporary, and it is restored with
  `git checkout -- src` before you commit. `git diff --stat -- src` must print nothing at commit
  time. If a case finds a defect, report it and pin or record it. Do not fix it.
- Commit trailer, which OVERRIDES any model name you would write yourself:
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`
- Run the e2e command in the FOREGROUND, with a 600000 ms tool timeout:
  `npm run test:e2e -- tests/e2e/<file>.e2e.ts`. Never start two e2e runs at once, and never run
  `npm run check` locally.
- Checks before every commit, all exiting 0:
  `npx vue-tsc -noEmit`, `npx oxlint --deny-warnings <changed files>` and
  `npx eslint --max-warnings 0 <changed files>`.
- Test-file budgets: at most 450 lines per file and at most 100 lines per function. A `describe`
  callback is a function, so split a long `describe` into two.
- Make every edit containing a backtick, `$` or `${` with the Edit or Write tool. Never use
  `node -e` or `sed` through Bash for those: bash expands them and truncates the file.
- The host runs in English (`--lang=en`), so assert the English copy. The copy lives in
  `src/presentation/i18n/locales/en.ts` and `src/presentation/i18n/locales/en/*.ts`.
- Wait with `expect.poll`, never with a sleep. The one exception is a **measured window** — "does X
  appear within N ms" — written as a named constant with its reason beside it.
- **Mutation gate, per case:** break exactly the clause in `src/`, run the case and see it go red on
  THAT assertion, restore, and name the mutation in the commit message. A pin whose fact belongs to
  Obsidian has no plugin mutation; the commit message says so.
- **Measure before asserting** where the spec says "measure". Run once with the assertion written
  as a `console.log` of the observed value. Then write the assertion to what you saw and remove the
  log. Do not commit probe files.
- Each task updates the manual case's Runs table, and the tracker row it answers, with what it
  measured, in the same commit. That includes anything unexpected.

## Review Focus

- **A measured window too short on a loaded CI runner.** Each window must be the documented delay
  plus a margin of at least 3x. Q2's window is the index's 500 ms debounce, so 3000 ms.
- **A case green for the wrong reason.** An `include` or selector matching nothing, or an
  `aria-disabled` read on an element that is not the one the step names. Each case must first
  assert that the thing it inspects exists: a count greater than 0, `color-contrast` in the axe
  passes, the canvas existing.
- **A plant that the plugin never read.** Every planted incident must first be seen: a paused strip
  or a refused write, before the case asserts anything past it.
- **Case order dependence.** Every case seeds its own project. Nothing reads another case's vault.
- **Leftover wrapped host methods.** A wrapped `app.vault.create`, or a held promise, is restored in
  a `finally` block, so a failed case does not hang its teardown.

 * Renderer-side collector for A01. Installed through the host, so it sees what the plugin logs
 * after the next load. The collector survives a plugin disable and re-enable, because the
 * renderer window does.
 */
export async function collectRendererErrors(browser: NativeBrowser): Promise<void> {
	await browser.execute(() => {
		const sink: string[] = [];
		(window as unknown as { __rpErrors: string[] }).__rpErrors = sink;
		const original = console.error.bind(console);
		console.error = (...args: unknown[]) => {
			sink.push(args.map(String).join(' '));
			original(...args);
		};
		window.addEventListener('error', (event) => sink.push(`error: ${event.message}`));
		window.addEventListener('unhandledrejection', (event) => sink.push(`unhandledrejection: ${String(event.reason)}`));
	});
}

	browser.execute(() => (window as unknown as { __rpErrors?: string[] }).__rpErrors ?? []);

/** Hold every `vault.create` until the test releases it. Restored by `releaseCreates(…, true)`. */
async function holdCreates(browser: NativeBrowser): Promise<void> {
	await browser.executeObsidian(({ app }) => {
		const vault = app.vault as unknown as { create: (...args: unknown[]) => Promise<unknown>; __rpOriginalCreate?: unknown };
		const original = vault.create.bind(vault);
		let release!: () => void;
		const gate = new Promise<void>((resolve) => { release = resolve; });
		(window as unknown as { __rpRelease: () => void }).__rpRelease = release;
		vault.__rpOriginalCreate = original;
		vault.create = async (...args: unknown[]) => { await gate; return original(...args); };
	});
}

async function releaseCreates(browser: NativeBrowser, restore: boolean): Promise<void> {
	await browser.executeObsidian(({ app }, unwrap) => {
		(window as unknown as { __rpRelease?: () => void }).__rpRelease?.();
		const vault = app.vault as unknown as { create: unknown; __rpOriginalCreate?: unknown };
		if (unwrap && vault.__rpOriginalCreate) vault.create = vault.__rpOriginalCreate;
	}, restore);
}

async function listed(ui: Ui): Promise<string[]> {
	return ui.projectView().$$('.rp-project-list__name').map((element) => element.getText());
}
