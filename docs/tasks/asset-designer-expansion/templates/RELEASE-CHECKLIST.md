# Asset Designer beta release checklist

Candidate commit:
Reviewer / date / environment:

- [ ] AD00 baseline and AD01 contract accepted; existing requirement mappings updated.
- [ ] AD02–AD14 integrated with task-level verification on the correct history.
- [ ] AD15 end-to-end scenarios and mandatory host checks passed.
- [ ] Build, lint, coverage, static analysis and audit have recorded dispositions.
- [ ] New geometry supported by every current consumer; no silent export omissions.
- [ ] Legacy v1/v2 migration and unsupported future-version refusal verified.
- [ ] Backup-based upgrade/recovery path exercised in disposable data.
- [ ] Wrong-unit, false-save, data-loss, frozen-state and unreachable-control defects resolved.
- [ ] Light/dark, compact panes and keyboard alternatives verified.
- [ ] Performance/usability results name their conditions and limitations.
- [ ] User documentation explains shared edits, clearance meaning and precision limitations.
- [ ] No unfinished or nonfunctional controls advertised.
- [ ] Known limitations and outstanding lower-severity issues explicitly accepted.
- [ ] Release authorization received before tag/push/publication.
