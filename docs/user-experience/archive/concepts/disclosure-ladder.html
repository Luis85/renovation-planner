Six rungs of one surface

Disclosure ladder is the only deliverable that states an order, and an order is the thing prose shows worst. Each card below is the same view at one rung.

Its own rule decides what these can draw: hidden means absent — no greyed tab, no placeholder, no coming-soon. So what a rung does not open simply is not in the stage. The absent groups are named in each card's footer, which is a note to a reviewer and not a thing a renovator would see.

What opens when

The six groups are Information Architecture's. A rung is promoted by the existence of the entity the previous rung produces — never a count, never a setting, never elapsed time — and a promoted rung never demotes.
