The same editor in German

de.ts answers six keys today, so the strings below are proposed, not shipped. What is not proposed is the problem: German compounds run 30–60% longer against rails fixed at 210 and 252px.

Measured, at an 878px pane: nothing overflows — not the toolbar, not the status bar, not the seven inspector actions. Nicht gespeicherte Änderungen is 29 characters against 15 and still fits. The one real loss is user data: a zone named Wohnzimmer im Erdgeschoss loses 24px of its tail in a 132px box. Labels survive translation here; names do not survive being long, and no translator ever sees them. Every name in this rail therefore carries a title — hover one.
