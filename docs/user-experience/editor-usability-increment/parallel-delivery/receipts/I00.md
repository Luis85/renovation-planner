## Conditional decisions

### U4 overlap chooser — conditional-deferred

Do not add a named chooser in I00 or I09 by default. Current code already resolves overlapping candidates through `SelectTool.targetAt(...)` with `cycle: event.modifiers.alt`; `EditorSurface.vue` reissues pointer state when Alt changes, and the canvas context menu uses the same candidate resolver with `cycle: event.altKey`. There is no evidence in this packet of a failing native/novice T6 task, and the mockup explicitly does not approve a chooser merely because it is drawn.

I09 may introduce a chooser only after recorded evidence that the current visible route fails target identification, and then must define candidate order, label/context, current target, keyboard focus, Escape-without-selection-change, hidden/locked/group behaviour and selection/Details synchronization. Otherwise ship only clarity fixes and retain this decision as tested-deferred. This receipt does **not** claim a user study or an accessibility pass.

### Arbitrary-corner keyboard/non-drag route — conditional-deferred

No new interaction is approved. `EditorSurface.vue` provides whole-selection arrow nudges, not a vertex-scoped keyboard branch; `SelectTool` still has a pointer vertex-drag path. The current source also contains `OutlinePointsForm.vue` and the issue record describes it as a numeric inspector route, but that conflicts with this increment's explicit instruction not to restore the rejected coordinate editor. I00 neither removes nor treats that existing form as an approved replacement.

I18 remains blocked on a concrete, human-approved interaction over existing geometry commands. Until that decision and native keyboard/non-drag verification exist, the unsupported task is independently changing an arbitrary room/area vertex without dragging. The release consequence is that this scope cannot be reported as passing the applicable non-drag/keyboard accessibility requirement or as an AA pass; the rejected coordinate editor must not be silently reinstated as the answer.
