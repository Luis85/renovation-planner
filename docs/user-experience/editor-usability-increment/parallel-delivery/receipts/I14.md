## Shared-file integration resolution

The guard could not be implemented in an owned visual layer: `SelectTool.pointerDown`
starts Room body/vertex drags, wall endpoint edits, element/label/rotation moves and group moves
even while `InteractionLayer` has hidden the handles. `EditorSurface` cannot distinguish a
marquee selection from one of those gestures without duplicating the tool's hit-testing.

1. Added a `canMutateGeometry: () => boolean` dependency to
   `src/presentation/editor/tools/select-tool.ts`. In Renovate it must leave ordinary target
   selection and marquee selection available, but block every gesture start and cancel an
   in-flight geometry gesture if the perspective changes. This covers zone body/vertex,
   selected-group, wall endpoint, element, label and rotation starts; no preview, command or
   history entry may result.
2. In `src/presentation/editor/tools/registerEditorTools.ts`, the predicate comes from the
   leaf's `useRenovationSession()` and pass `() => session.perspective === 'plan'` to
   `SelectTool`. This keeps the decision with the registered tool rather than manufacturing a
   second hit-test in `EditorSurface`.
3. Added the same perspective gate to `src/presentation/editor/nudge.ts` and wired it in
   `src/presentation/editor/runtime.ts` when constructing `createNudgeSelectionAction`. The
   owned `EditorSurface` wrapper is an early UI guard; the action itself needs the authoritative
   no-write boundary for any future caller.
4. Made editable scalar dimension controls in
   `src/presentation/editor/resize/RoomDimensionLabels.vue` Plan-only. CI DOM evidence found
   `[data-rp-dimension="width"]` and `[data-rp-dimension="depth"]` still rendered in Renovate;
   purely informational edge measurements may remain. Add a Renovate assertion that those
   dimension-edit buttons are absent while the selected Room/context remains visible.
5. Updated the now-obsolete success expectations in
   `tests/presentation/editor/renovateRoomManipulation.test.ts`, and add focused pointer
   assertions for Room body/vertex and wall endpoint in Renovate. Verify selection, pan,
   navigation, eligible renovation actions, the existing draft confirmation/busy guard, and the
   Review-return snapshot stay unchanged.
