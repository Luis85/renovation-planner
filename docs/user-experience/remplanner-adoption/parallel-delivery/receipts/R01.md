## Delivered contract

Selected doors and windows now expose Width, Along wall and Swing controls on the canvas,
through the Inspector, and from the keyboard/right-click menu. All routes open the shared DOM
panel, which provides exact fields, visible 10 mm steps, current-host identity, hinge/side/angle,
local preview, Apply and Cancel. Width changes retain the current centre; offset changes retain
width. Invalid containment and overlap proposals are refused rather than clamped.

The panel retains raw fractional-millimetre draft values through steps and never introduces a
default swing for an untouched opening. It uses the existing guarded Structure command with
initial-write admission. Pending reads retire on selection, tool, perspective or unmount changes.
Opening Move is now Plan-only at its action boundary; history replay remains independent.
