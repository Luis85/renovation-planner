# Execute work and track the renovation

## Goal

Know what needs attention during execution and retain a record of actual work and spending.

## Actor and entry

A private renovator working in Obsidian; no CAD or data-model expertise is assumed. The renovation moves from planning into active execution.

## Main flow

1. Inspect active work, tasks, procurement needs, blockers, and upcoming work.
2. Continue the relevant room or work item in its context.
3. Record progress and actual costs as work proceeds.
4. Attach documentation and evidence for the work performed.
5. Return to the project overview for current attention items and the next useful action.

## Alternatives and recovery

- Execution-oriented guidance is a proposed adaptation of the long-term Project Home, not approval of invented status or progress metrics.
- The source does not define a task-status vocabulary, procurement state machine, or automatic replanning behavior.
- Unrelated work should remain reachable when a regional operation fails.

## Outcome

Current work, known blockers, actual costs, and supporting documentation remain connected to the renovation.
