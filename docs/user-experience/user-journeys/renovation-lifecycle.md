# Navigate the renovation lifecycle

## Goal

Move from renovation intent to completion while always understanding project, place, activity, and next steps.

## Actor and entry

A private renovator working in Obsidian; no CAD or data-model expertise is assumed. A private renovator begins or returns to a property renovation over an extended period.

## Main flow

1. Create or open a project and establish renovation intent.
2. Understand the property and model useful spaces, with drawings optional.
3. Describe desired changes, plan work, and estimate costs as detail becomes available.
4. Add scheduling when useful, execute work, and track progress and evidence.
5. Review completion and preserve the project for later reference.

## Alternatives and recovery

- Start → Understand → Model → Design → Plan → Estimate → Schedule → Execute → Track → Complete is a conceptual path, not a required sequence.
- Older portfolio dashboards, completion percentages, and mandatory wizards are superseded for current project entry by UJ-P01/P02.
- This lifecycle is a long-term concept, not evidence that all stages or navigation destinations are implemented.

## Outcome

The renovation remains a coherent project across stages, with optional detail and preserved context.
